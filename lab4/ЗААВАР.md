## 2. Онол (Lec4)

**Урсгал (thread)** — CPU ашиглалтын үндсэн нэгж: өөрийн *thread ID, программын тоолуур, регистрийн багц, стэйк*-тэй; харин код, өгөгдөл, нээсэн файлуудыг процессынхоо бусад урсгалтай **дундаа хэрэглэнэ**.

**Мулти-урсгалын давуу тал:** Responsiveness (нэг хэсэг блоклогдсон ч бусад нь ажиллана), Resource sharing, Economy (урсгал үүсгэх нь процесс үүсгэхээс хөнгөн), Scalability (мулти-цөм ашиглана).

**Concurrency vs Parallelism:** concurrency — олон ажил ээлжлэн урагшлах (нэг цөм дээр ч), parallelism — бодитоор нэгэн зэрэг (олон цөм).
**Өгөгдлийн параллелчлал** — өгөгдлийг хуваан цөм бүр дээр ижил үйлдэл; **даалгаврын параллелчлал** — урсгал бүр өөр үйлдэл (жнь 4.22).

**Amdahl-ын хууль:** `speedup ≤ 1 / (S + (1−S)/N)`, S — дараалсан хэсэг, N — цөм. N→∞ бол → 1/S.

**Загварууд:** Many-to-One (нэг блоклогдвол бүгд), **One-to-One** (Linux, Windows), Many-to-Many, Two-level.

**Pthreads үндсэн API:**
```c
pthread_t tid;
pthread_create(&tid, NULL, runner, arg);   // шинэ урсгал runner(arg)-ийг ажиллуулна
pthread_join(tid, NULL);                   // урсгал дуусахыг хүлээнэ (процессын wait()-тэй адил)
pthread_mutex_lock(&m); ... pthread_mutex_unlock(&m);   // critical section
```
Хөрвүүлэхдээ `-pthread` заавал.

**OpenMP** (далд урсгал): `#pragma omp parallel` — цөмийн тоогоор урсгал үүсгэнэ; `#pragma omp for` — давталтыг урсгалуудад хуваана; `reduction(+:x)` — урсгал бүр өөрийн хуулбар дээр нэмээд эцэст нь нийлүүлнэ. Хөрвүүлэх: `-fopenmp`.

**Java урсгал:** `new Thread(() -> ...).start()` (Runnable lambda). JVM ихэвчлэн OS-ийн kernel урсгал (one-to-one) болгоно.

### 4.22 — Статистик (`stats.c`) — *даалгаврын параллелчлал*
3 worker урсгал (`calc_average`, `calc_minimum`, `calc_maximum`) — тус бүр **глобал** хувьсагч (`average`, `minimum`, `maximum`) тохируулна; эцэг урсгал `pthread_join` ×3 хийгээд хэвлэнэ. Урсгалууд өөр өөр хувьсагч бичдэг тул mutex хэрэггүй.
```bash
./stats 90 81 78 95 79 72 85
The average value is 82.86        ← номд "82" (бүхэл); бодит дундаж 580/7 = 82.857
The minimum value is 72
The maximum value is 95

```

### 4.23 — Анхны тоо (`primes.c`)
Эцэг урсгал тоог шалгаад `pthread_create(&tid, NULL, print_primes, &n)` — аргументыг **заагчаар** дамжуулна. Урсгал **Эратосфений шигшүүр**-ээр (O(n log log n)) олж хэвлэнэ.

### 4.24 — π Monte Carlo, Pthreads (`monte_carlo.c`)
[-1,1]×[-1,1] квадратад санамсаргүй цэг; `x² + y² ≤ 1` бол тойрог дотор. Талбайн харьцаа: π·1² / 2² = π/4 → **π ≈ 4 · (тойрог доторх) / (нийт)**. Урсгал үр дүнг **глобал** `circle_points`-д бичиж, эцэг join хийсний дараа π-г тооцно. `rand_r(&seed)` — thread-safe санамсаргүй тоо (`rand()` нь дотоод төлөвтэй тул урсгалд аюултай).
```bash
./monte_carlo 10000000
Points: 10000000, in circle: 7854923
Estimated pi = 3.141969
```
Цэг олон байх тусам π-д ойртоно (алдаа ~ 1/√N).

### 4.25 — π Monte Carlo, OpenMP (`monte_carlo_omp.c`)
```c
#pragma omp parallel reduction(+:hits)
{
    unsigned int seed = time(NULL) ^ (omp_get_thread_num() * 7919u);   // урсгал бүр өөр seed
    #pragma omp for
    for (long i = 0; i < total; i++) { ... if (x*x + y*y <= 1.0) hits++; }
}
double pi = 4.0 * hits / total;      // parallel region-ээс ГАДНА — нэг л удаа
```
```bash
./monte_carlo_omp 10000000
Threads: 12, points: 10000000, in circle: 7853450
Estimated pi = 3.141380  (0.044 s)
```
Цөмийн тоог өөрчилж турших: `OMP_NUM_THREADS=1 ./monte_carlo_omp 100000000` vs `OMP_NUM_THREADS=12 ...` → хугацааны ялгааг Amdahl-тай холбож тайлбарлаж болно.

### 4.27 — Фибоначчи (`fib.c`)
Хүү урсгал **дундын массив** `fib[]`-д fib₀…fibₙ₋₁-ийг бичнэ; эцэг `pthread_join`-оор хүлээгээд хэвлэнэ (§4.4 — эцэг хүүгээс өмнө хэвлэж болохгүй). `unsigned long long`-д fib(93) хүртэл багтдаг тул n ≤ 94.

### 4.28 — PID manager, 100 урсгал (`pid_manager_mt.c`)
3.20-ийн bitmap PID manager + 100 урсгал: урсгал бүр `allocate_pid()` → 1–3 сек `sleep` → `release_pid()`.
**Mutex яагаад нэмсэн бэ:** `allocate_pid()` нь "0 бит хайх → 1 болгох" гэсэн **хоёр алхамтай**. Хоёр урсгал зэрэг ижил 0 битийг олбол **нэг PID-ийг хоёуланд нь** олгоно (race condition). `pthread_mutex_lock/unlock` нь хайх+тавих үйлдлийг critical section болгоно. (Ном үүнийг 6, 7-р бүлэгт нэмдэг; бид урьдчилан хийсэн.) Шалгалт: `in_use[pid]` тоолуураар давхардал тоолно.
```bash
./pid_manager_mt | tail -3
Thread  99: got pid 399, sleeping 1 s

100 threads done. Max active pids: 100, duplicate pids: 0
```

### 4.29 — Мулти-урсгалт echo server (`EchoServerMT.java`)
Клиент бүрт урсгал; **`InputStream`** ашигладаг (байтын түвшин → binary өгөгдөл ч зөв); `in.read(buf)` **-1** буцаавал клиент холболтоо хаасан → давталтаас гарна.
```bash
java EchoServerMT.java          # port 6007
nc 127.0.0.1 6007               # 2 терминалаас зэрэг: бичсэнээ буцааж авна
```
Шалгагдсан: A клиент холбогдсон хэвээр байхад B-д үйлчилсэн; 256 байт санамсаргүй binary өгөгдөл яг ижил буцсан.

## 6. Багш асууж магадгүй асуултууд

| Асуулт | Товч хариулт |
|---|---|
| Процесс ба урсгалын ялгаа? | Процесс — тусдаа хаягийн орон, нөөцтэй; урсгал — процесс доторх гүйцэтгэлийн нэгж, с/о-г дундаа хэрэглэнэ, өөрийн стэйк/регистртэй. |
| `pthread_join` хийхгүй бол? | `main` дуусахад процесс бүх урсгалын хамт дуусна → үр дүн гарахгүй байж болно; мөн урсгалын нөөц чөлөөлөгдөхгүй (zombie урсгал). |
| `pthread_create`-д аргумент яаж дамжуулдаг вэ? | `void *` заагчаар (4.23-т `&n`). Утга нь урсгал ажиллах хүртэл хүчинтэй байх ёстой. |
| Race condition гэж юу вэ? | Хоёр урсгал дундын өгөгдөлд зэрэг хандаж, үр дүн гүйцэтгэлийн дарааллаас хамаарах. 4.28-д mutex-ээр сэргийлсэн. |
| 4.22-т яагаад mutex хэрэггүй вэ? | Урсгал бүр өөр хувьсагч бичдэг, `nums` массивыг зөвхөн уншдаг. |
| `rand()` vs `rand_r()`? | `rand()` дотоод глобал төлөвтэй → thread-safe биш; `rand_r(&seed)` төлөвөө аргументаар авна. |
| OpenMP `reduction` юу хийдэг вэ? | Урсгал бүрт `hits`-ийн хувийн хуулбар үүсгэж, эцэст нь `+`-ээр нийлүүлнэ → mutex хэрэггүй, хурдан. |
| Яагаад 12 урсгал үүссэн бэ? | OpenMP анхдагчаар логик CPU-ийн тоогоор (`nproc` = 12) урсгал үүсгэдэг. `OMP_NUM_THREADS`-ээр өөрчилнө. |
| Thread pool гэж юу вэ? | Урьдчилан үүсгэсэн урсгалуудын цуглуулга — хүсэлт бүрт шинэ урсгал үүсгэхгүй, бэлэн урсгал ашиглана → хурдан, урсгалын тоо хязгаартай (Java `Executors.newFixedThreadPool`). Серверүүдийг ингэж сайжруулж болно. |
| Linux урсгалыг юугаар үүсгэдэг вэ? | `clone()` систем дуудалт (Lec4 слайд 53) — флагуудаар юуг хуваалцахыг заана; Linux "task" гэж нэрлэдэг. |
