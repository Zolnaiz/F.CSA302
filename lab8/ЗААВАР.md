## 1. Онол — товч

- **Логик хаяг** — CPU үүсгэдэг, программ үүнийг л хардаг. **Физик хаяг** — санах ойн жинхэнэ хаяг. MMU ажиллах явцад хөрвүүлнэ.
- **Хуудаслалт (paging):** логик санах ой → тогтмол хэмжээтэй **хуудас**, физик → ижил хэмжээтэй **фрэйм**. **Хуудасны хүснэгт** хуудас → фрэйм.
- Хуудас $2^n$ байт бол: **хуудасны дугаар** = хаяг >> n, **оффсет** = хаяг & (2^n − 1). Физик хаяг = фрэйм × 2^n + оффсет.
- **Логик хаягийн бит** = log₂(хуудасны тоо) + log₂(хуудасны хэмжээ); **физик** = log₂(фрэймийн тоо) + log₂(хуудасны хэмжээ) (9.4, 9.9).
- **Энгийн хуудасны хүснэгт** — виртуал хуудас бүрт 1 бичлэг (процесс бүрт). **Урвуу хуудасны хүснэгт** — физик фрэйм бүрт 1 бичлэг (системд нэг) (9.8, 9.10).
- **First / best / worst-fit** — үргэлжилсэн хуваарилалтад нүх сонгох стратеги (9.6).

## 2. Программ — `addresses.c` (9.28)

```c
uint32_t address = (uint32_t)v;     // 32 бит — unsigned
uint32_t page   = address >> 12;    // 4 KB = 2^12 → дээд 20 бит
uint32_t offset = address & 0xFFF;  // доод 12 бит
```
- `strtoull` + шалгалт: сөрөг, тоо биш (`abc`, `12x`), `2^32 − 1`-ээс их → алдаа, exit 1.
- Хуваах/үлдэгдлийн оронд shift ба mask — хуудасны хэмжээ 2-ын зэрэг байдгийн шалтгаан (9.2).
